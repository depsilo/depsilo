# T16 预热任务进度与结果 UI

- 现有 CacheManage 预热弹窗接入真实 `job_id`；任务已接受和任务完成保持
  独立提示，不再把提交成功当作缓存完成。
- 使用同一个 query owner 每 1.5 秒轮询任务状态；到达 `succeeded`、
  `partial`、`failed`、`cancelled` 或 `interrupted` 后停止轮询。
- 展示有界逐包结果列表，并由后端明确标注 metadata cached；没有百分比、
  预计时间或完整离线依赖集承诺。
- 取消按钮受写权限控制，调用 T15 协作式取消接口；已有包列表和错误输入
  状态保留。关闭弹窗不会取消后台任务。
- 已补双语文案，前端类型、ESLint、i18n、`admin-forms.spec.ts`（6 项）和
  `make check` 均通过。

任务历史遵循 T15 的有界保留语义；重启后的未完成任务显示为 `interrupted`，
不会自动重放上游请求。现有浏览器用例覆盖提交表单
和受控状态展示，未声称已完成真实上游预热或跨重启证据。
