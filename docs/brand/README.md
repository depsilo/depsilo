# Depsilo Brand Assets

从 `depsilo-landingpage/logo` 提取的品牌资源，供各子项目开发参考。

## Logo 文件

### 图标（Icon Only）
| 文件 | 背景 | 用途 |
|------|------|------|
| `icon-light.svg` | 白色 (#ffffff) | 浅色背景场景 |
| `icon-dark.svg` | 深蓝 (#042C53) | 深色背景场景 |

### 横向组合（Horizontal Lockup）
| 文件 | 背景 | 用途 |
|------|------|------|
| `logo-horizontal-light.svg` | 浅色 | 网站头部、文档等 |
| `logo-horizontal-dark.svg` | 深色 | 深色导航栏、深色主题 |

### 堆叠组合（Stacked Lockup）
| 文件 | 背景 | 用途 |
|------|------|------|
| `logo-stacked-light.svg` | 浅色 | 启动页、关于页面 |
| `logo-stacked-dark.svg` | 深色 | 深色背景展示 |

## Logo 构成

**"Lightning Stack"** — 三色横条 + 白色闪电符号

- 闪电符号 clip-path: `polygon(45% 0%, 100% 0%, 55% 45%, 85% 45%, 15% 100%, 45% 55%, 15% 55%)`
- 图标圆角: 大尺寸 `24px`，小尺寸 `12px`
